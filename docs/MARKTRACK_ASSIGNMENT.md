## The assignment

A simple text-only social feed — think a stripped-down Facebook. Nothing fancy.

### What it needs to do

#### Accounts
- Sign up
- Log in
- Log out
- Authentication must use an email and password

#### Shared feed
- One shared feed of text-only posts
- No images
- No file uploads

#### Posts
- Create posts
- Edit posts
- Delete posts
- Including other people's posts. That's intentional; keep permissions simple.

#### Comments
- Comment on any post

#### Reactions
- React to any post
- A like counter is enough

#### Profiles
- A profile page per user
- The profile page should show the posts they've written

#### Seeded data
Seed the application with real-looking data before the reviewers open it:
- Several distinct users with real names
- Dozens of posts
- Existing comments
- Existing reactions

An empty feed is an automatic no.

#### Design
- Designed and professional-looking
- Not an unstyled default template

## Stack and hosting

### Application
- Next.js is the path of least resistance
- Netlify runs server components, route handlers, and server actions with no config

### Database
- Bring your own free database
- Neon has a free-forever Postgres tier with no card required, and works well here

### Cost
- This should cost you nothing
- If a step asks for a credit card, you're on the wrong tier — pick another one

### Public availability
- The link must be publicly reachable
- It must still be working when they open it, which can be days later
- Watch out for free tiers that sleep on inactivity
- Supabase pauses after a week and needs a manual unpause
- No localhost
- No screen recordings
